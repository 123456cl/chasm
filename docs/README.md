# 文档索引

本目录分两类：**对外发布的只有第一类**。

## 一、对外：框架手册（随仓库发布）

| 文件 | 内容 |
|---|---|
| `../CodeWiki.md` | **开发者手册**（第 0~25 章）：常用 API 与完整类型、性能与缓存规则、逐特性用法、构建与发布流程。**这是唯一要发的核心文档。** |
| `扩展点.md` | 扩展点（SPI）速查：可接入的位置、注册顺序、多模组共存约定。 |

## 二、内部：移植与排错记录（**不随仓库/产物发布**）

以下内容已在仓库根的 `.gitignore` 中排除（规则见 `docs/INT-*`、`docs/tetra-ui-*/`），只在本机保留：

| 文件 / 目录 | 内容 |
|---|---|
| `INT-port-notes.md` | 第三方模组适配与事故复盘的完整记录（原手册第 25~41 章）。只记行为语义与排错过程，不含第三方美术/数据文件。 |
| `INT-tetra-data-inventory.md` | 数据迁移清单：哪些数据已接引擎、哪些没有。 |
| `INT-progress-2026-09-22.md` | 阶段进度快照（带证据：命令输出 / file:line / 测试名）。 |
| `INT-plan-remaining.md` | 玩法层剩余计划。 |
| `tetra-ui-real-spec/` | 对标界面的逐节点规格与差距清单（见该目录 `README.md`）。 |
| `tetra-ui-probe/` | 界面探针：schema、样例 dump、用法（JSONL 逐帧记录界面结构，用于与自己实现逐节点比对）。 |

## 三、对外文档里怎么谈移植

`CodeWiki.md` 只在 §25 用**摘要 + 经验条目**的方式谈移植（不列第三方资产、不贴其数据文件、不逐条复述其内部实现）。
详细记录一律放上面的内部文件。

> **发布前请自行确认授权情况**：仓库与产物中**不应包含**任何第三方模组的美术资源、模型、音效或数据文件。
> 引用了第三方数据的模块（`tetra-port/`、`apoth-port/`）在取得作者许可前**已被 `.gitignore` 排除**；
> 拿到许可后删掉 `.gitignore` 第 43~46 行即可恢复。
